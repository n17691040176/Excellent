# 移动端城市合伙人随分润模式开关

日期：2026-09-11。本次根据用户要求，替代此前“原模式仍可独立购买席位”的行为。

## 当前行为

- ORIGINAL：隐藏个人中心城市合伙人入口；席位页面仅显示“暂未开放”，不展示城市列表、我的城市、报价、规则或购买按钮。席位列表接口返回 enabled=false 和空列表。
- CITY_PARTNER：恢复入口、列表和正常购买能力，原有同城唯一、禁止自我接替规则继续生效。
- 每次进入页面重新获取开关；前台停留时每 15 秒检查一次。请求失败默认关闭，不长期使用缓存。点击入口与购买按钮也重新确认；真正创建订单和发起支付时，后端刷新并锁定模式配置，禁止关闭后的新购。
- 旧的未付款席位订单保留取消能力，但关闭后不展示支付按钮，也不能重新发起支付。外部支付准备、模拟支付和内部支付入口均受保护。
- 已发起的第三方支付可能在关闭后回调，继续按既有订单履约及处理异常退款，保留付款事实和回调幂等。此开关不承诺撤回第三方已经签发的支付页面。
- 历史订单、佣金、席位持有关系和后台管理保留，便于查账和售后；不删除或重算历史记录。

- 文档验收、财务边界、原计算器对照：53 passed。
