---

## 3. 启动顺序建议

建议按以下顺序启动：

1. 启动 MySQL
2. 启动 Redis
3. 初始化并启动后端 `server/`
4. 启动后台管理端 `admin-web/`
5. 启动移动端 `mobile-h5/`

这样可以避免前端先启动后出现接口 401 / 404 / 连接失败的误判。

## 4. 后端启动说明

### 4.1 环境变量
参考文件：`server/.env.example`

当前默认关键配置：
- MySQL：`127.0.0.1:3306`
- Redis：`127.0.0.1:6379`
- 数据库名：`excellent_app`
- JWT 有效期：`1440` 分钟
- 允许前端来源：`5173` / `5174`

### 4.2 初始化数据库
建议先在 MySQL 中创建数据库：

```sql
CREATE DATABASE excellent_app DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 4.3 启动命令
在 PowerShell 中执行：

```powershell
cd D:\Excellent\server
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python app\db\init_db.py
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 4.4 可选脚本
当前仓库已有脚本：
- `server/scripts/init_db.ps1`
- `server/scripts/start_dev.ps1`
- `server/scripts/seed_data.py`

### 4.5 后端验收地址
- Swagger：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/health`

## 7. 联调建议流程

建议按以下顺序联调：

### 7.1 第一步：确认后端正常
打开：
- `http://127.0.0.1:8000/health`
- `http://127.0.0.1:8000/docs`

确认项：
- FastAPI 服务启动成功
- Swagger 可访问
- 无数据库连接报错
- 无 Redis 初始化报错

### 7.2 第二步：联调后台管理端
打开：
- `http://127.0.0.1:5173`

建议检查：
1. 默认管理员是否能登录
2. 首页概览是否能返回数据
3. 用户列表、套餐列表、提现列表是否可加载
4. 本地生活管理页是否可加载商家/订单/收益规则

### 7.3 第三步：联调移动端 H5
打开：
- `http://127.0.0.1:5174`

建议检查：
1. 注册 / 登录是否正常
2. 首页四大专区是否能加载列表
3. 套餐详情、商品详情是否可下单
4. 订单详情是否能展示订单项和抵扣信息
5. 本地生活服务下单后是否能进入本地生活订单页
6. 资产中心、佣金中心是否能读取当前用户数据
