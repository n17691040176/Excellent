- 用户货币展示统一为余额、佣金、积分。个人中心移除优惠券占位，资产页移除消费金和充电宝货币页签；佣金入口进入现有佣金中心。后台用户资产摘要保持三类，旧资产中心组件也统一展示。

## 正式部署仍需核对

1. 当前大量修改及新增文件尚未提交成固定发布版本。生产脚本拉取镜像仓库的 latest，不会自动上传或打包本地改动；发布前必须确认三端镜像包含本次修复，并记录镜像摘要供回退核对。
2. 生产数据库备份、恢复及实际库升级演练尚未执行。本轮是旧 schema 加少量样例数据的升级测试，没有覆盖生产数据量、历史坏账或真实重复内部结算账户；后者会阻止现有迁移启动。
3. 真实微信/支付宝支付、回调、退款、提现及真实短信未验收；本地使用模拟支付/短信。生产证书、回调域名与密钥需要在目标环境核实。
4. 既有财务边界仍然存在：订单完成立即释放佣金，余额不足可能阻止退款收回，成功席位的特殊全量冲正尚未实现；原模式区域代理奖在订单完成时首次读取配置计算。需要按这些实际规则运营。
5. 未执行长时间压力测试或真机 App/小程序、相机、厂商小程序联调，本轮浏览器验证对象为 H5。
