# 订单分润模式展示与筛选

日期：2026-09-11。

后台订单增加“分润模式”列及筛选：原分润、新分润、未锁定。详情显示订单保存的模式和规则版本；legacy 显示“历史规则”。订单类型新增“城市合伙人席位”选项，区分席位交易和采用新分润的商品订单。

普通商品订单未付款时显示“待锁定”，未付款即取消的订单显示“未锁定”，两者均归入未锁定筛选。付款后按订单保存的模式展示；历史已付款或已退款订单，即使没有新版 mode_locked_at，仍按其保存的模式展示。城市席位订单按其固定的新模式显示。后台当前开关不会重新标记历史订单。

筛选在数据库分页前执行，可与订单状态、支付状态、订单类型、关键词组合，团队管理员仍仅能查看本团队数据。本次没有新增数据库列或重写历史账务。

浏览器截图复查复现了快速重置后查询时旧响应覆盖新结果的问题，已增加请求序号保护，仅允许最后发出的请求更新列表、总数及加载状态。浏览器通过延迟重置响应验证此保护。

移动端购物订单页面保持原样；佣金明细每条记录增加“原分润 / 新分润”简短标识，取自各自流水，不读取当前全局模式。同时把 FROZEN / SETTLED / CANCELED 显示为“待结算 / 已结算 / 已撤销”，已撤销记录不再计入待结算数量。

- 完整后端 343 passed，另有 2 subtests passed、1 warning；包含实际 MySQL 检查，无跳过。文档、边界及原计算器对照 53 passed。
- 修改前端文件 ESLint 通过；后台、移动端、服务端 Docker 构建通过并更新本地。
- 浏览器使用本地真实订单验证三种筛选、规则版本、重置和席位类型选项；独立测试账户通过登录查看其实际原/新两笔佣金标识及中文状态，无页面异常。
