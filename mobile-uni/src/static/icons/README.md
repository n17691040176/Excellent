# App Icons

Put your real app icons and splash assets here.

Suggested files:
- `app-icon.png`
- `app-icon-round.png`
- `store-icon-1024.png`
- `splash-bg.png`
- `splash-logo.png`

After preparing assets, wire them into:
- `src/manifest.json`
- HBuilderX visual manifest settings if you use cloud packaging
